# 今日气场 Today Aura

「今日气场 Today Aura」是一个每日形象与穿搭建议产品，面向 18-35 岁女性用户。

它帮助用户在出门前快速回答一个具体问题：

> 我今天该怎么出现？

产品不会把重点放在算命、电商导购或复杂身材分析上，而是把个人风格、今日场景、天气、情绪、精力状态和轻量趣味运势内容结合起来，生成一份可执行的每日审美决策建议。

## 产品定位

Today Aura 是一个每日审美决策助手。

它关注的不是“买什么”，而是“今天怎么搭”；不是判断用户好不好看，而是帮助用户降低穿搭焦虑，更快进入当日状态。

核心价值包括：

- 帮用户在出门前快速确定今日主色、辅助色和点缀色。
- 根据今日场景给出可执行的穿搭方向，而不是泛泛的时尚描述。
- 根据情绪和精力状态提供有情绪价值的形象建议。
- 用轻量仪式感让每日穿搭变成一种自我确认。
- 生成可分享的今日气场卡片，方便用户保存或发给朋友。

## 第一版 MVP 包含什么

第一版只做高频、轻量、可验证的核心流程：

- 用户档案：基础风格偏好、常穿色、希望呈现的气质。
- 今日场景选择：通勤、约会、聚会、运动、休闲、面试、旅行等。
- 今日状态输入：天气、情绪、精力、自信度、想要的气场。
- 颜色推荐：今日主色、辅助色、点缀色，并解释原因。
- 穿搭建议：上装、下装、外套、鞋包的方向建议。
- 妆容配饰建议：妆感、发型、首饰、香氛或小物建议。
- 分享卡片：生成一张包含今日气场关键词、颜色和建议摘要的卡片。

## 第一版不做什么

为了保持 MVP 聚焦，第一版明确不做：

- 不做复杂 3D 试衣。
- 不做完整衣橱管理。
- 不做真实电商交易。
- 不做真人身材分析。
- 不做重度星盘、占卜或玄学系统。
- 不做大量社区内容和关注关系。

## 用户使用路径

1. 用户打开产品。
2. 系统读取用户档案。
3. 用户选择今日场景。
4. 用户输入今日状态。
5. 系统生成今日气场结果。
6. 用户查看颜色、穿搭、妆容配饰建议。
7. 用户保存或分享今日气场卡片。

## 本地运行

当前前端工程使用 Next.js、TypeScript 和 Tailwind CSS。

```bash
npm install
npm run dev
```

常用检查命令：

```bash
npm run lint
npm run typecheck
npm run build
```

MVP 0.1 不依赖数据库、登录、支付、真实 AI API、真实语音输入或天气 API。用户档案、今日输入和生成结果暂时保存到浏览器 `localStorage`。

## Vercel 部署

推荐使用 Vercel 部署小范围测试链接。

部署前先确认：

```bash
npm run lint
npm run typecheck
npm run build
```

Vercel 项目设置：

- Framework Preset：Next.js。
- Install Command：使用默认值，或 `npm install`。
- Build Command：使用默认值，或 `npm run build`。
- Output Directory：留空，使用 Next.js 默认输出。
- Environment Variables：MVP 0.1 暂不需要配置。

部署成功后，Vercel 会生成 Preview URL 和 Production URL。小范围用户测试优先使用 Preview URL，确认首页、用户档案、今日输入、结果页和分享卡片流程正常后，再切换到 Production。
